# MAC Movies 🎬

A modern, database-driven movie catalog website built with Node.js, Express, and MySQL.

## ✨ Features
- **Modern UI:** Beautiful dark-themed, Netflix-inspired design with hover animations.
- **Dynamic Data:** Pulls movie information dynamically from a local MySQL database.
- **Movie Posters:** Displays movie images alongside their title, genre, and description.

## 🛠️ Tech Stack
- **Backend:** Node.js & Express.js
- **Frontend:** EJS (Embedded JavaScript), HTML5, Custom CSS
- **Database:** MySQL (XAMPP)

## 🚀 How to Run Locally

1. **Database Setup:**
   - Open XAMPP and start **MySQL**.
   - Open phpMyAdmin.
   - Create a database named `movies_db`.
   - Run the SQL code found in `schema.sql` to generate the table and sample movies.

2. **Server Setup:**
   - Open the project folder in your terminal.
   - Run `npm install` to download required packages.
   - Run `npm start` to boot up the server.
   
3. **View the Website:**
   - Open your web browser and go to `http://localhost:3000`
